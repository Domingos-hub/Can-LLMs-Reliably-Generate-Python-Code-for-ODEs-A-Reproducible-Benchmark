# Can-LLMs-Reliably-Generate-Python-Code-for-ODEs-A-Reproducible-Benchmark-
We benchmark 120 manually curated first-order ODE problems from real-world applications, reviewed by four Angolan lecturers. We assess 10 LLMs (3 code-specialized, 7 general) on generating executable Python that formulates and solves these equations, scoring execution and numerical correctness separately.
